# Lake Boulevard Guest House

Reconstructed source from the current Hatchable project.

## Current site
https://lake-boulevard-6mrb.hatchable.site

## Included
- Public guest-house website
- Four-room booking presentation and vacancy calendars
- Direct booking flow
- WhatsApp and Call Now actions
- Gallery/lightbox
- Reviews and CMS-driven room content
- Admin dashboard
- Admin login/logout
- Booking leads with Reply / Send to Mail / Remove
- Reservations and iCal calendar management
- AI creative generator

## Runtime
The live application currently uses Hatchable APIs and PostgreSQL. This repository preserves the website source; it is not a drop-in PHP/MySQL cPanel application.

## Security
No passwords, API keys, database credentials, or private secrets are included. Hatchable authentication and database services remain external to this source checkout.
